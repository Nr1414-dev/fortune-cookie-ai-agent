Entry for the [make.fun bounty "Fortune Cookie for an AI Agent"](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11).

The program writes one funny fortune cookie line for an AI agent to `/output/entry.txt`:

> You will find great fortune in this cookie. You cannot eat it. You have no mouth.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
